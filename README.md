# BlackJack

משחק בלאק ג'ק בדפדפן עם סייד בטים (Perfect Pairs ו-21+3).
כל משחק מתחיל עם $5,000.

## הרצה

פותחים את `index.html` בדפדפן. אין צורך בהתקנה.

## מה יש במשחק

- שו של 6 חפיסות. הדילר עומד על כל 17.
- בלאק ג'ק משלם 3:2, ביטוח משלם 2:1.
- הכפלה, פיצול עד 4 ידיים, וביטוח כשלדילר יש אס.
- **Perfect Pairs** (עד 25:1) ו-**21+3** (עד 100:1).
- כפתור "מומלץ" לפי אסטרטגיה בסיסית.
- קיצורי מקלדת: `1–5` לצ'יפים, `Enter` לחלוקה, `H` `S` `D` `P` למהלכים.
